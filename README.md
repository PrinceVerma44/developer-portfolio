## 🌟 Overview

**Prince Verma — The Developer's Domain** is an immersive, 3D anime-themed personal portfolio website built for **Prince Verma**, a first-year B.Tech Computer Science Engineering student specializing in **Artificial Intelligence and Machine Learning** at **Newton School of Technology** (in collaboration with **Ajeenkya DY Patil University**).

Inspired by supernatural anime aesthetics (such as *Jujutsu Kaisen* domain expansions and classic Japanese sunset atmospheres), this portfolio merges creative 3D environments, interactive canvas simulations, procedural Web Audio synthesis, and an interactive developer CLI terminal into a single, high-performance web experience.

## 🚀 Instant Launch (Zero Setup Required)

**No localhost, no Node.js, no `npm install`, and no build commands needed.**

1. Download or clone this repository:

2. Open the project folder.
3. **Double-click [`index.html`](file:///Users/princeverma/Documents/roblox/index.html)** (or right-click → *Open with Chrome / Safari / Edge / Firefox*).
4. The website will execute directly using the `file://` protocol.

## ⛩️ Features & Architecture

### 1. 🎬 Cinematic Anime Opening (Domain Expansion)
- Japanese-inspired animated domain seal (`領域`), concentric rotating celestial rings, and atmospheric particles.
- Cinematic reveal: *"THE WORLD IS BUILT BY THOSE WHO CREATE."*
- Unveils Prince Verma's academic degree, AI & ML specialization, and main tagline.
- Interactive controls: `[ ENTER MY DOMAIN ]`, `[ EXPLORE MY WORK ]`, and `[ SKIP INTRO ]`.

### 2. 🌌 3D Japanese Sunset World & Original Character (Three.js r128)
- **Procedural Japanese Sunset Sky**: Canvas-generated sky dome gradient transitioning from cosmic purple to fiery sunset orange and sakura horizon.
- **Traditional Architecture**: Silhouette mountain ridges, multi-tiered pagoda structures, and a vermilion Torii gate.
- **Traditional Rooftop**: Curved Japanese roof tiles (*Kawara*) where the character stands.
- **Original 3D Anime Developer Character**:
  - Young male anime developer in oversized black techwear jacket with high upturned collar.
  - Spiky stylized hair geometry and glowing cyber visor/eyes.
  - Idle breathing dynamics (procedural sinusoidal translation & dilation).
  - Orbiting supernatural cursed energy orbs around hands in cyan and purple.
  - Smooth mouse-tracking parallax (character head and camera follow cursor position).
- **Floating Sakura Petals**: Dynamic 3D particle system with aerodynamic tumbling and wind drift.
- **Fail-Safe WebGL Fallback**: If WebGL is unavailable, a dedicated HTML5 2D Canvas seamlessly renders the animated sunset sky, mountains, and falling sakura petals.

### 3. 🎵 Procedural Web Audio Ambient Synthesizer
- Built using the browser's native **Web Audio API** (`AudioContext`, `OscillatorNode`, and `GainNode`).
- Generates gentle, atmospheric pentatonic chords based on the traditional Japanese **Insen scale** (D, Eb, G, A, C).
- **100% self-contained**: Zero external MP3/audio files to fetch.
- **Strictly user-initiated**: Never autoplays; toggled via the sound icon in the navbar.

## 💻 Tech Stack

- **Markup & Styling**: HTML5, CSS3 (Glassmorphism, 3D Transforms, CSS Grid, Flexbox, Media Queries)
- **Core Scripting**: Vanilla JavaScript (ES6+, zero bundler dependency, zero local `fetch()`)
- **3D Graphics Engine**: [Three.js r128](https://threejs.org/) (UMD CDN Build)
- **Motion & Transitions**: [GSAP 3](https://greensock.com/gsap/) (UMD CDN Build)
- **Audio Synthesis**: Native Web Audio API (Insen scale oscillator synthesis)
- **Procedural Canvases**: HTML5 2D Canvas API (Neural net, Equalizer, Project previews, 2D Fallback)
